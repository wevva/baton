## 13. 범위 밖 (정직하게)
| 항목 | 이유 |
|---|---|
| 문 잠금·창문·실내등 인계 | 순정 경고·현대 블루링크 영역. 다음 운전자에게 불필요 |
| 경음기·와이퍼·미러·연결 장치·휠 결함 (DVIR 항목) | 해당 신호 없음 |
| 타이어 공기압 수치 | 시스템 전용 권한 → TPMS 경고등으로 대체 |
| 급발진 등 차량 제어 개입 | 읽기 전용 앱. 제동 계통 경고 인계까지만 |
| 차내 아동 방치 | 현대 순정(ROA)과 중복 |
